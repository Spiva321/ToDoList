# Мои задачи — To-Do List на Flask

Простой, современный и полностью рабочий список задач: добавляйте дела,
отмечайте выполненные и удаляйте ненужные. Все задачи хранятся в SQLite и
сохраняются после обновления страницы и перезапуска приложения.

![Стек](https://img.shields.io/badge/Flask-3.x-000000?logo=flask&logoColor=white)
![Python](https://img.shields.io/badge/Python-3.11%2B-3776AB?logo=python&logoColor=white)
![SQLite](https://img.shields.io/badge/SQLite-3-003B57?logo=sqlite&logoColor=white)

## Возможности

- Добавление задач через кнопку «Добавить» или клавишу Enter.
- Защита от пустых задач и строк из одних пробелов.
- Отметка задач выполненными и возврат их в активные.
- Удаление задач с подтверждением.
- Активные задачи отображаются выше выполненных.
- Счётчики: всего задач, активных, выполненных.
- Адаптивный светлый интерфейс для компьютеров, планшетов и телефонов.
- Данные хранятся в SQLite, а не в `localStorage`.
- Приложение работает и без JavaScript (JS добавляет только удобства).

## Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone <URL-вашего-репозитория>
cd todo-list
```

### 2. Создайте виртуальное окружение

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

Linux / macOS:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Настройте переменные окружения (необязательно)

Скопируйте `.env.example` в `.env` и задайте свой секретный ключ:

```bash
cp .env.example .env
python -c "import secrets; print(secrets.token_hex(32))"
```

Полученное значение запишите в `SECRET_KEY`. Без `.env` приложение тоже
запустится: для локальной разработки секретный ключ будет сгенерирован
автоматически.

Ограничьте доступ к файлу с секретом (macOS / Linux):

```bash
chmod 600 .env
```

`.env` уже исключён в `.gitignore` и не должен попадать в репозиторий.
Если ключ когда-либо попал в Git или был скомпрометирован — сгенерируйте
новый, замените значение в `.env` и перезапустите приложение.

### 5. Запустите приложение

```bash
python app.py
```

Откройте в браузере: <http://127.0.0.1:5000>

Каталог `instance/` и файл базы `instance/todo.db` создаются автоматически
при первом запуске.

### Режим отладки

По умолчанию отладка выключена. Чтобы включить её локально, задайте в `.env`:

```text
FLASK_DEBUG=1
```

### Если на macOS открывается белая страница

macOS может занимать порт `5000` системным сервисом **AirPlay Receiver**.
В этом случае `http://localhost:5000` отвечает пустой страницей (HTTP 403),
хотя Flask работает. Открывайте точный адрес:

```text
http://127.0.0.1:5000
```

Также можно отключить приёмник AirPlay: «Системные настройки» → «Основные» →
«AirDrop и Handoff» → выключить «Приёмник AirPlay».

Либо запустите приложение на другом порту:

```bash
PORT=5001 python app.py
```

и откройте <http://127.0.0.1:5001>.

## Переменные окружения

| Переменная     | Назначение                                            | По умолчанию            |
|----------------|-------------------------------------------------------|-------------------------|
| `SECRET_KEY`   | Ключ для подписи сессий и flash-сообщений              | случайный при запуске   |
| `DATABASE_URL` | Строка подключения к базе                             | `sqlite:///instance/todo.db` |
| `FLASK_DEBUG`  | Режим отладки (`1` — включён, `0` — выключен)         | `0`                     |
| `HOST`         | Адрес, на котором слушает сервер                      | `127.0.0.1`             |
| `PORT`         | Порт сервера                                          | `5000`                  |

## Деплой

Приложение готово к запуску на хостинге с поддержкой Python (Render,
Railway, PythonAnywhere и аналогичные).

Важно: многие платформы используют эфемерную файловую систему — файл SQLite
может исчезнуть при перезапуске контейнера. В этом случае:

- подключите постоянный диск и укажите путь к базе через `DATABASE_URL`;
- либо используйте внешнюю базу данных (например, PostgreSQL) и задайте
  `DATABASE_URL` с её строкой подключения.

Для продакшена обязательно задайте `SECRET_KEY`, выключите `FLASK_DEBUG` и
запускайте приложение через WSGI-сервер, например Gunicorn:

```bash
pip install gunicorn
gunicorn "app:app" --bind 0.0.0.0:8000
```
