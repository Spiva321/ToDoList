# AGENT.md — To-Do List на Flask (Python)

## 1. Цель проекта

Разработать простой, современный и удобный веб-сайт **To-Do List (Список задач)** с использованием Python и Flask.

Приложение должно позволять пользователю добавлять задачи, отмечать их выполненными, удалять задачи и сохранять их между обновлениями страницы.

Проект должен быть полностью рабочим, иметь аккуратный дизайн и быть готовым к публикации на GitHub и деплою.

## 2. Технологический стек

Использовать следующие технологии:

- **Python 3.11+** — основной язык программирования.
- **Flask** — backend и маршрутизация.
- **SQLite** — база данных для постоянного хранения задач.
- **Flask-SQLAlchemy** — работа с базой данных через ORM.
- **HTML5** — структура страниц.
- **CSS3** — стилизация интерфейса.
- **JavaScript** — интерактивность на frontend.
- **Jinja2** — шаблоны Flask.

Не использовать React, Vue или другие frontend-фреймворки. Проект должен оставаться простым.

## 3. Основной функционал

### 3.1. Добавление задач

- Пользователь может добавить новую задачу через текстовое поле.
- Для добавления должна быть кнопка «Добавить».
- Добавление также должно работать по нажатию Enter.
- Нельзя добавлять пустые задачи или строки, состоящие только из пробелов.
- После добавления поле ввода должно очищаться.

### 3.2. Отметка выполненных задач

- У каждой задачи должен быть checkbox.
- При нажатии на checkbox задача получает статус выполненной.
- Выполненные задачи должны визуально отличаться от активных (например, зачеркнутый текст и приглушенный цвет).
- Статус должен сохраняться в SQLite.
- Пользователь должен иметь возможность вернуть выполненную задачу в активные.

### 3.3. Удаление задач

- У каждой задачи должна быть кнопка удаления.
- При нажатии задача удаляется из базы данных.
- После удаления список автоматически обновляется.

### 3.4. Сохранение данных

- Все задачи должны храниться в SQLite.
- После перезапуска приложения задачи не должны пропадать.
- После обновления страницы состояние задач должно сохраняться.
- Не использовать localStorage вместо базы данных.

### Общая концепция

- Небольшая карточка с закругленными углами.

## 6. Backend: Flask

Реализовать следующие маршруты:

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/` | Главная страница |
| POST | `/add` | Добавление задачи |
| POST | `/toggle/<id>` | Изменение статуса |
| POST | `/delete/<id>` | Удаление задачи |

Использовать Flask-SQLAlchemy для взаимодействия с SQLite.

### Модель Task

Модель должна содержать:

- `id` — уникальный идентификатор.
- `title` — название задачи.
- `completed` — статус выполнения (Boolean).
- `created_at` — дата и время создания.

Все пользовательские данные необходимо валидировать. При обращении к несуществующему ID возвращать корректный ответ 404 или безопасно перенаправлять пользователя на главную страницу с уведомлением.
